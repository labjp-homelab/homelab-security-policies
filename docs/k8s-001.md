# K8S-001 · Los contenedores no corren como root

| | |
|---|---|
| **Severidad** | high |
| **Categoría** | Pod Security |
| **Modo actual** | Audit |
| **Política** | `run-as-non-root` ([`policies/kubernetes/validatingpolicy-k8s-001-run-as-non-root.yaml`](https://github.com/labjp-homelab/homelab-security-policies/blob/main/policies/kubernetes/validatingpolicy-k8s-001-run-as-non-root.yaml)) |

## Por qué

Un proceso con uid 0 dentro del contenedor está a una vulnerabilidad del kernel o a un montaje mal puesto de ser root en el nodo. Exigir runAsNonRoot hace que el kubelet se niegue a arrancar una imagen que corra como root.

## Cómo cumplirla

```yaml
securityContext:
  runAsNonRoot: true
  runAsUser: 1000   # o el uid sin privilegios que defina la imagen
```

## Qué comprueba exactamente

Expresión CEL que evalúa Kyverno sobre cada contenedor del pod:

```
variables.containers.all(c, c.?securityContext.?runAsNonRoot.orValue(object.spec.?securityContext.?runAsNonRoot.orValue(false)) == true)
```
