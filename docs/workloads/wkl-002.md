## Por qué

Sin requests el planificador reparte a ciegas, y sin límite de memoria un contenedor puede agotar el nodo y provocar el desalojo de otros servicios.

## Cómo cumplirla

```yaml
resources:
  requests:
    cpu: 50m
    memory: 64Mi
  limits:
    memory: 256Mi
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(c, has(c.resources) && has(c.resources.requests) && has(c.resources.requests.memory) && c.resources.requests.memory != '' && has(c.resources.requests.cpu) && c.resources.requests.cpu != '' && has(c.resources.limits) && has(c.resources.limits.memory) && c.resources.limits.memory != '')
```
