# K8S-004 · Perfil seccomp del runtime

| | |
|---|---|
| **Severidad** | medium |
| **Categoría** | Pod Security |
| **Modo actual** | Audit |
| **Política** | `seccomp-runtime-default` ([`policies/kubernetes/validatingpolicy-k8s-004-seccomp-runtime-default.yaml`](https://github.com/labjp-homelab/homelab-security-policies/blob/main/policies/kubernetes/validatingpolicy-k8s-004-seccomp-runtime-default.yaml)) |

## Por qué

Sin perfil seccomp el contenedor puede invocar cualquier syscall del kernel, incluidas las que usan muchos exploits de escape. RuntimeDefault bloquea las peligrosas sin romper aplicaciones normales.

## Cómo cumplirla

```yaml
securityContext:
  seccompProfile:
    type: RuntimeDefault
```

## Qué comprueba exactamente

Expresión CEL que evalúa Kyverno sobre cada contenedor del pod:

```
variables.containers.all(c, c.?securityContext.?seccompProfile.?type.orValue(object.spec.?securityContext.?seccompProfile.?type.orValue('')) in ['RuntimeDefault', 'Localhost'])
```
