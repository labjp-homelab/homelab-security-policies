## Por qué

Un ExternalName hacia localhost hace que el proxy del clúster apunte a servicios locales del nodo.

## Cómo cumplirla

```yaml
# No usar type: ExternalName con externalName: localhost
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.type != 'ExternalName' || object.spec.externalName != 'localhost'
```
