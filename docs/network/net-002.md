## Por qué

externalIPs permite interceptar tráfico hacia cualquier IP (CVE-2020-8554).

## Cómo cumplirla

```yaml
# No declarar spec.externalIPs
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
!has(object.spec.externalIPs) || size(object.spec.externalIPs) == 0
```
