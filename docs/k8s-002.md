# K8S-002 · Sin escalada de privilegios

| | |
|---|---|
| **Severidad** | high |
| **Categoría** | Pod Security |
| **Modo actual** | Audit |
| **Política** | `disallow-privilege-escalation` ([`policies/kubernetes/validatingpolicy-k8s-002-disallow-privilege-escalation.yaml`](https://github.com/labjp-homelab/homelab-security-policies/blob/main/policies/kubernetes/validatingpolicy-k8s-002-disallow-privilege-escalation.yaml)) |

## Por qué

Con allowPrivilegeEscalation (verdadero por defecto) un binario setuid o una capability heredada puede dar al proceso más privilegios que su padre. Debe declararse false de forma explícita.

## Cómo cumplirla

```yaml
securityContext:
  allowPrivilegeEscalation: false
```

## Qué comprueba exactamente

Expresión CEL que evalúa Kyverno sobre cada contenedor del pod:

```
variables.containers.all(c, c.?securityContext.?allowPrivilegeEscalation.orValue(true) == false)
```
