# K8S-003 · Sin capabilities de Linux

| | |
|---|---|
| **Severidad** | medium |
| **Categoría** | Pod Security |
| **Modo actual** | Audit |
| **Política** | `drop-all-capabilities` ([`policies/kubernetes/validatingpolicy-k8s-003-drop-all-capabilities.yaml`](https://github.com/labjp-homelab/homelab-security-policies/blob/main/policies/kubernetes/validatingpolicy-k8s-003-drop-all-capabilities.yaml)) |

## Por qué

El runtime concede por defecto capabilities como NET_RAW o CHOWN que casi ninguna aplicación necesita y que facilitan ataques en la red del nodo. Se quitan todas y se añade solo la imprescindible, justificada.

## Cómo cumplirla

```yaml
securityContext:
  capabilities:
    drop: ["ALL"]
```

## Qué comprueba exactamente

Expresión CEL que evalúa Kyverno sobre cada contenedor del pod:

```
variables.containers.all(c, 'ALL' in c.?securityContext.?capabilities.?drop.orValue([]))
```
