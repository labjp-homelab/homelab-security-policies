## Por qué

runAsUser: 0 fuerza root aunque la imagen declare otro usuario.

## Cómo cumplirla

```yaml
securityContext:
  runAsUser: 1000   # cualquier uid distinto de 0
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.?securityContext.?runAsUser.orValue(1) > 0
```

```
variables.allContainers.all(container, container.?securityContext.?runAsUser.orValue(1) > 0)
```
