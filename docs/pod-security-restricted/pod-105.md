## Por qué

Solo perfiles seccomp que filtran syscalls. La política de Kyverno acepta el valor sin declarar; aquí se recomienda declararlo siempre para no depender del nodo.

## Cómo cumplirla

```yaml
securityContext:
  seccompProfile:
    type: RuntimeDefault
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.?securityContext.?seccompProfile.?type.orValue('RuntimeDefault') in ['RuntimeDefault', 'Localhost'] && variables.allContainers.all(container, container.?securityContext.?seccompProfile.?type.orValue('RuntimeDefault') in ['RuntimeDefault', 'Localhost'])
```
