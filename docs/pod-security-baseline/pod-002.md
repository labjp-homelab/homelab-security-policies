## Por qué

Con hostNetwork, hostPID o hostIPC el pod comparte la red, los procesos o la memoria compartida del nodo: puede espiar tráfico, ver procesos de otros pods o atacarlos.

## Cómo cumplirla

```yaml
spec:
  hostNetwork: false
  hostPID: false
  hostIPC: false
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
!(variables.hostNetwork || variables.hostIPC || variables.hostPID)
```
