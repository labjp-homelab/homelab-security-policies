## Por qué

Un hostPath monta un directorio del nodo dentro del contenedor: con la ruta adecuada (el socket del runtime, /etc, /var/lib/kubelet) el contenedor controla el nodo.

## Cómo cumplirla

```yaml
volumes:
  - name: data
    persistentVolumeClaim:     # o emptyDir para datos temporales
      claimName: data
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.?volumes.orValue([]).all(volume, !has(volume.hostPath))
```
