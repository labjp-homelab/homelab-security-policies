## Por qué

Capabilities como SYS_ADMIN o NET_ADMIN dan poderes de root sobre el kernel o la red del nodo. Solo se admiten las del conjunto por defecto de Baseline.

## Cómo cumplirla

```yaml
securityContext:
  capabilities:
    drop: ["ALL"]
    add: ["NET_BIND_SERVICE"]   # solo si de verdad hace falta
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(container, container.?securityContext.?capabilities.?add.orValue([]).all(capability, capability == '' || capability in variables.allowedCapabilities))
```
