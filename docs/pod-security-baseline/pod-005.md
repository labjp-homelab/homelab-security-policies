## Por qué

Un contenedor HostProcess de Windows corre directamente en el nodo, sin aislamiento.

## Cómo cumplirla

```yaml
securityContext:
  windowsOptions:
    hostProcess: false
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(container, container.?securityContext.?windowsOptions.?hostProcess.orValue(false) == false)
```
