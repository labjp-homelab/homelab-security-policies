## Por qué

hostPort publica el contenedor directamente en la IP del nodo, saltándose Services, NetworkPolicies y el Gateway.

## Cómo cumplirla

```yaml
ports:
  - containerPort: 8080   # sin hostPort; exponer con un Service
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(container, container.?ports.orValue([]).all(port, port.?hostPort.orValue(0) == 0))
```
