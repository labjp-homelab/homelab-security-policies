## Por qué

Las variables de entorno acaban en logs, volcados de error y en el entorno de los procesos hijos. Un secreto montado como archivo se expone menos.

## Cómo cumplirla

```yaml
volumes:
  - name: creds
    secret:
      secretName: app-creds
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.containers.all(container, container.?env.orValue([]).all(env, !has(env.valueFrom) || !has(env.valueFrom.secretKeyRef)))
```

```
object.spec.containers.all(container, container.?envFrom.orValue([]).all(envFrom, !has(envFrom.secretRef)))
```
