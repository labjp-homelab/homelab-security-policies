# K8S-006 · Límite de memoria declarado

| | |
|---|---|
| **Severidad** | medium |
| **Categoría** | Recursos |
| **Modo actual** | Audit |
| **Política** | `require-memory-limits` ([`policies/kubernetes/validatingpolicy-k8s-006-require-memory-limits.yaml`](https://github.com/labjp-homelab/homelab-security-policies/blob/main/policies/kubernetes/validatingpolicy-k8s-006-require-memory-limits.yaml)) |

## Por qué

Un contenedor sin límite de memoria puede agotar el nodo y provocar que el kubelet desaloje a otros servicios: es una denegación de servicio que no necesita ninguna vulnerabilidad.

## Cómo cumplirla

```yaml
resources:
  requests:
    memory: 64Mi
  limits:
    memory: 256Mi
```

## Qué comprueba exactamente

Expresión CEL que evalúa Kyverno sobre cada contenedor del pod:

```
variables.containers.all(c, c.?resources.?limits.?memory.orValue('') != '')
```
