# K8S-007 · Imagen fijada, sin latest

| | |
|---|---|

| **Categoría** | Supply Chain |
| **Modo actual** | Audit |
| **Política** | `pin-image-reference` ([`policies/kubernetes/validatingpolicy-k8s-007-pin-image-reference.yaml`](https://github.com/labjp-homelab/homelab-security-policies/blob/main/policies/kubernetes/validatingpolicy-k8s-007-pin-image-reference.yaml)) |

## Por qué

Un tag como latest puede apuntar mañana a otra imagen: lo que se revisó y firmó no es necesariamente lo que corre. Se fija por digest (o, como mínimo, por un tag de versión), y así la firma y el SBOM describen exactamente lo desplegado.

## Cómo cumplirla

```yaml
image: registry.example/app:1.4.2@sha256:<digest>
```

## Qué comprueba exactamente

Expresión CEL que evalúa Kyverno sobre cada contenedor del pod:

```
variables.containers.all(c, c.image.contains('@sha256:') || (c.image.substring(c.image.lastIndexOf('/') + 1).contains(':') && !c.image.endsWith(':latest')))
```
