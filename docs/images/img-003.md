## Por qué

Las imágenes de registries desconocidos pueden no estar escaneadas ni firmadas. La lista sale del inventario real del clúster (3 oct 2026); las imágenes sin registry son de Docker Hub.

## Cómo cumplirla

```yaml
# Usar un registry de la lista; para uno nuevo, añadirlo aquí con su motivo
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(c, (c.image.split('/')[0].contains('.') || c.image.split('/')[0].contains(':') ? c.image.split('/')[0] : 'docker.io') in variables.allowedRegistries)
```
