## Por qué

latest puede apuntar mañana a otra imagen: lo que se revisó y firmó no es necesariamente lo que corre.

## Cómo cumplirla

```yaml
image: ghcr.io/labjp-homelab/app:1.4.2
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.containers.all(container, container.image.contains(':'))
```

```
object.spec.containers.all(container, !container.image.endsWith(':latest'))
```
