## Por qué

Montar el socket de containerd, CRI-O o Docker equivale a ser root en el nodo: permite lanzar contenedores privilegiados.

## Cómo cumplirla

```yaml
# No montar /var/run/containerd/containerd.sock ni equivalentes
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.hasVolumes || variables.volumesWithHostPath.all(volume, !volume.hostPath.path.matches('/var/run/docker.sock'))
```

```
variables.hasVolumes || variables.volumesWithHostPath.all(volume, !volume.hostPath.path.matches('/var/run/containerd/containerd.sock'))
```

```
variables.hasVolumes || variables.volumesWithHostPath.all(volume, !volume.hostPath.path.matches('/var/run/crio/crio.sock'))
```

```
variables.hasVolumes || variables.volumesWithHostPath.all(volume, !volume.hostPath.path.matches('/var/run/cri-dockerd.sock'))
```
