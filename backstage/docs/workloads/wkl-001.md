## Por qué

Si no se puede escribir en la raíz del contenedor, un atacante no puede dejar binarios ni modificar el código que se ejecuta. Lo escribible va a un emptyDir aparte.

## Cómo cumplirla

```yaml
securityContext:
  readOnlyRootFilesystem: true
volumeMounts:
  - name: tmp
    mountPath: /tmp
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(container, has(container.securityContext) && has(container.securityContext.readOnlyRootFilesystem) && container.securityContext.readOnlyRootFilesystem == true)
```
