## Por qué

El namespace default no tiene cuotas, límites ni NetworkPolicies propias: lo que cae ahí queda fuera de la gobernanza.

## Cómo cumplirla

```yaml
metadata:
  namespace: <namespace propio, declarado en la gobernanza>
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
namespaceObject.metadata.name != 'default'
```
