## Por qué

Un Secret de tipo service-account-token no caduca. Los pods deben usar tokens proyectados, que caducan y se rotan solos.

## Cómo cumplirla

```yaml
# Usar el token proyectado (automountServiceAccountToken) o TokenRequest
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.type != 'kubernetes.io/service-account-token'
```
