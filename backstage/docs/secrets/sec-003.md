## Por qué

Con el montaje automático, cualquier pod de la ServiceAccount lleva un token del API server aunque no lo use; si el pod cae, el token sirve para moverse por el clúster. Que lo pida solo el pod que lo necesita, en su propia especificación.

## Cómo cumplirla

```yaml
apiVersion: v1
kind: ServiceAccount
automountServiceAccountToken: false   # el pod que lo necesite lo activa en su spec
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.?automountServiceAccountToken.orValue(true) == false
```
