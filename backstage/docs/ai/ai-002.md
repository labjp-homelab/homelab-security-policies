## Por qué

A un revisor LLM se le puede convencer con un prompt injection escondido en el propio cambio. Si una carga declara que la aprobó un agente de IA, una persona tiene que haber revisado el diff y dejado su aprobación en Git.

## Cómo cumplirla

```yaml
metadata:
  annotations:
    security.labjp.xyz/ai-reviewed: blue-reviewer
    security.labjp.xyz/human-approved: "true"   # la pone una persona en Git
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.metadata.annotations[?'security.labjp.xyz/human-approved'].orValue('') == 'true'
```
