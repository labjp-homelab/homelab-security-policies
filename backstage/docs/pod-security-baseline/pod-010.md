## Por qué

Los sysctls fuera del conjunto seguro cambian parámetros del kernel que afectan a todos los pods del nodo.

## Cómo cumplirla

```yaml
# Solo: kernel.shm_rmid_forced, net.ipv4.ip_local_port_range,
# net.ipv4.ip_unprivileged_port_start, net.ipv4.tcp_syncookies, net.ipv4.ping_group_range
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.?securityContext.?sysctls.orValue([]).all(sysctl, sysctl.?name.orValue('') in variables.allowedSysctls)
```
