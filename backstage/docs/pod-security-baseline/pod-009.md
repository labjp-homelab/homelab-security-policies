## Por qué

seccomp Unconfined deja al contenedor invocar cualquier syscall del kernel, incluidas las que usan los exploits de escape.

## Cómo cumplirla

```yaml
securityContext:
  seccompProfile:
    type: RuntimeDefault
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.hasValidSeccompProfile && variables.allContainers.all(container, container.?securityContext.?seccompProfile.?type.orValue('Localhost') in variables.allowedProfileTypes)
```
