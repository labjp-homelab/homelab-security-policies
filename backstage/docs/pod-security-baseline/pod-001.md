## Por qué

Un contenedor privilegiado tiene casi los mismos permisos que un proceso del nodo: puede ver sus dispositivos y escapar del aislamiento sin necesidad de un exploit.

## Cómo cumplirla

```yaml
securityContext:
  privileged: false   # o simplemente no declararlo
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(container, container.?securityContext.?privileged.orValue(false) == false)
```
