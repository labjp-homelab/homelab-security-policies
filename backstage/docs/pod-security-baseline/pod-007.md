## Por qué

procMount Unmasked expone rutas de /proc que el runtime oculta y que revelan información del nodo o permiten modificarlo.

## Cómo cumplirla

```yaml
securityContext:
  procMount: Default   # o no declararlo
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(container, container.?securityContext.?procMount.orValue('Default') == 'Default')
```
