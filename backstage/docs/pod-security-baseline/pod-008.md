## Por qué

Cambiar el usuario, rol o tipo SELinux puede quitar al contenedor el confinamiento que le aplica el runtime.

## Cómo cumplirla

```yaml
# No declarar seLinuxOptions, o solo el tipo container_t / container_init_t / container_kvm_t
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.hasValidSELinuxType && variables.allContainerTypes.all(container, container.?securityContext.?seLinuxOptions.?type.orValue('') == '' || variables.seLinuxTypes.exists(type, type == container.securityContext.seLinuxOptions.type))
```

```
variables.hasValidSELinuxUserRole && variables.allContainerTypes.all(container, container.?securityContext.?seLinuxOptions.?user.orValue('') == '' && container.?securityContext.?seLinuxOptions.?role.orValue('') == '')
```
