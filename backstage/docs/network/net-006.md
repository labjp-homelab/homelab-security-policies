## Por qué

Una ruta del Gateway externo llega desde Internet. Sin SecurityPolicy (OIDC) ni AuthPolicy, cualquiera la usa; si es pública, el motivo tiene que quedar escrito.

## Cómo cumplirla

```yaml
# Una SecurityPolicy o AuthPolicy que apunte a la ruta, o, si es pública a propósito:
metadata:
  annotations:
    security.labjp.xyz/public: "webhooks firmados con HMAC"
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
!variables.external || variables.public || variables.protected
```
