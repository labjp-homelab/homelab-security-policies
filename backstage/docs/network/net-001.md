## Por qué

Un NodePort abre un puerto en todos los nodos y se salta el Gateway y su TLS. En el homelab se publica por Envoy Gateway o por MetalLB.

## Cómo cumplirla

```yaml
spec:
  type: ClusterIP   # y una HTTPRoute en el Gateway
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.spec.type != 'NodePort'
```
