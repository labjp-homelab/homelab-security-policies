## Por qué

Un paso que hace `curl ... | sh` ejecuta código que nadie revisó ni fijó, con las credenciales del pipeline: quien controle esa URL controla el build.

## Cómo cumplirla

```yaml
# Descargar una versión fija y verificar su hash antes de usarla:
script: |
  curl -fsSLo /tmp/tool.tar.gz https://example.com/tool-1.2.3.tar.gz
  echo "<sha256>  /tmp/tool.tar.gz" | sha256sum -c -
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
object.kind != 'Task' || object.spec.?steps.orValue([]).all(s, !s.?script.orValue('').matches(variables.pattern))
```

```
variables.pipelineTasks.all(t, t.?taskSpec.?steps.orValue([]).all(s, !s.?script.orValue('').matches(variables.pattern)))
```
