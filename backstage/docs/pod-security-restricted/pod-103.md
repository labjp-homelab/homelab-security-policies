## Por qué

Con allowPrivilegeEscalation (verdadero por defecto) un binario setuid puede dar al proceso más privilegios que su padre. Debe declararse false.

## Cómo cumplirla

```yaml
securityContext:
  allowPrivilegeEscalation: false
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
variables.allContainers.all(container, container.?securityContext.allowPrivilegeEscalation.orValue(true) == false)
```
