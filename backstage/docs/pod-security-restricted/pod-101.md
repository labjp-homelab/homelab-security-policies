## Por qué

Con runAsNonRoot el kubelet se niega a arrancar una imagen que corra como root: un proceso con uid 0 está a una vulnerabilidad del kernel de ser root en el nodo.

## Cómo cumplirla

```yaml
securityContext:
  runAsNonRoot: true
```

## Qué comprueba exactamente

Expresiones CEL que evalúa Kyverno (deben cumplirse todas):

```
(object.spec.?securityContext.?runAsNonRoot.orValue(false) == true && variables.ctnrs.all(c, c.?securityContext.?runAsNonRoot.orValue(true) == true)) || variables.ctnrs.all(c, c.?securityContext.?runAsNonRoot.orValue(false) == true)
```
